BuildOne 2.0 — 빌드 스크립트
========================================================

이 폴더의 스크립트가 V1 전달본(빌드원시스템\프로토타입_HTML)을 바탕으로
2.0 화면(빌드원시스템_V2\프로토타입_HTML)을 만듭니다. V1 파일은 읽기만 하고 고치지 않습니다.

■ 화면 다시 만들기
--------------------------------------------------------
  이 폴더에서:
      python build_v2.py
  → 00_로그인 · 01_통합메뉴 · 02_건물정보 · 03_사용자권한 · 04_안전보건 · 05_오늘의할일 을 새로 씀

  주의: 프로토타입_HTML의 html 파일을 직접 고치면 다음 빌드 때 덮어써집니다.
        고칠 내용은 아래 스크립트에 넣어야 합니다.
  예외: common_perm.js · common_header.js 는 프로토타입_HTML 안의 파일이 원본입니다.
        고친 뒤 build_v2.py를 다시 돌리면 화면들의 ?v= 번호가 바뀌어 브라우저가 새 파일을 받습니다.

■ 파일
--------------------------------------------------------
  build_v2.py          전체 빌드 (로그인 · 메뉴 · 건물정보 · 사용자권한, 아래 단계를 차례로 실행)
  v2_step_popup.py     건물정보: 건물 목록 · 기본정보 팝업 · 새 건물 · 삭제
  v2_step_users.py     사용자 · 권한: ① 사용자 · 접근 건물 ▾
  v2_step_safety.py    안전보건 (V1 27_안전보건 기반 + 2.0 변경 전부) · 메뉴 안전보건 그룹
  v2_step_dash.py      대시보드 › 오늘의 할 일 + 처음 화면 고정
  v2_dashboard.html    오늘의 할 일 화면 원본
  v2_step_fresh.py     로그인 · 메뉴 클릭 때 항상 새 화면(?t=)

  폴더 위치는 이 파일 기준으로 찾습니다(빌드원시스템_V2\빌드스크립트).
  V1 원본은 같은 상위 폴더의 빌드원시스템\프로토타입_HTML 이어야 합니다.

■ 기획서 다시 만들기 (문서생성 폴더)
--------------------------------------------------------
  처음 한 번:   npm install
  만들기:       node gen.js ..\..\기획문서              (6개 모두)
                node gen.js ..\..\기획문서 safe         (dash · bld · safe 중 고르기)
  내용:         doc_dash.js · doc_bld.js · doc_safe.js (서식은 lib.js, 화면 사진은 img)
  화면 확인:    powershell -File topdf.ps1 -InDir <docx 폴더> -OutDir <pdf 폴더>   (Word 필요)
