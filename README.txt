■ 메뉴
--------------------------------------------------------
  📊 대시보드      └ 오늘의 할 일   ← 로그인 · 새로고침 · 계정 전환 때 항상 이 화면부터
  🏢 건물관리      └ 건물정보 등록
  🦺 안전보건      └ 경영책임자 현황(대표만) / 나의 안전보건 / 교육 관리 / 위험성평가 /
                      안전교육 리스트 / 위험성평가 리스트
                      (교육 관리 = 예전 교육 공지 · 서명 현황 + 교육 계획 · 실시를 한 목록으로.
                       [+ 교육 등록]의 교육 방법에 [공지]가 있고, 고르면 교육 공지 보내기 창(알림톡 · 서명 마감)으로 이어짐 —
                       공지는 대표 · 관리자만. 목록에서 [교육 방법]으로 공지만, [교육 상태]로 완료 · 미완료(예정 · 진행중)만
                       골라 볼 수 있고, 미서명 공지는 [알림톡 다시])
                      (위험성평가: 잡힌 회의의 [회의 기록 보기]와 관리소장 위험성평가 리스트 카드에
                       [🖨 회의용 평가표 출력] — 회의 전에 뽑아 검토할 위험요인 · 판단 기준을 보며 이야기하고,
                       회의에서 정한 점수 · 새로 찾은 위험 · 직원 의견 · 참석 서명을 손으로 적음)
                      (끝난 위험성평가 회의의 평가표는 회의를 마친 때 내용 그대로 고정 — 나중에 위험요인을
                       [수정]해도 회의 결과 · 출력물은 바뀌지 않음. 개선 완료 여부 · 사진만 계속 반영)
                      (위험성평가 회의 현황은 화면 위 [건물]에서 고른 건물만,
                       경영책임자 현황 · 오늘의 할 일은 접근할 수 있는 건물 전체)
                      (장소는 각 건물의 지금 이름으로 표시 — 예: 플랫폼포지 (관악) 로비)
                      (위쪽 [건물] 목록 맨 위 [전체] — 모든 건물을 건물 이름을 붙여 한 화면에.
                       새 위험요인 등록은 건물을 하나 고른 뒤, 줄의 [수정] · [완료]는 그 건물로 바뀐 뒤 바로 실행.
                       [+ 교육 등록]은 총무 · 이사 · 대표 · 관리자만 — 회사 모든 직원(건물별로 묶어 표시)이 대상이고,
                       저장하면 건물마다 한 건씩 만들어져 건물별로 출석 · 서명을 받음.
                       [반기]는 [건물] 바로 옆. 화면을 열 때마다 건물은 [전체], 반기는 기준일 연도의 상반기부터)
                      (직책별로 보이는 항목이 다름 — 현장 직원은 나의 안전보건만)
                      경영방침 · 이수 현황 · 작업허가 · 순회점검 · 반기 점검 · 기록 이력은 뺌
                      (메뉴 · 화면 안 바로가기 · 주소로도 열리지 않음)
  ⚙️ 시스템 설정   └ 사용자 · 권한

■ 권한이 실제로 적용됩니다
--------------------------------------------------------
  역할별 권한(없음 / 조회 / 편집)은 common_perm.js의 기본 권한표를 따르고, 로그인할 때 적용됩니다.
  (화면의 ② 역할 · 권한 · ③ 접근 건물 탭은 뺐습니다 — 접근 건물은 ① 사용자에서 ▾로 고름)
    · 없음  → 메뉴가 보이지 않고, 주소로 직접 열어도 "권한이 없습니다"
    · 조회  → 메뉴에 [조회] 표시, 화면은 보기 전용 (저장 · 등록 · 삭제 버튼 숨김)
    · 편집  → 모든 기능 사용
  시스템관리자(admin)는 항상 전체 편집입니다.
  접근 건물을 바꾸면 그 사용자는 다음 로그인부터 적용됩니다(본인 계정은 바로).

  기본 권한
    역할            건물관리   안전보건   시스템 설정
    관리자          편집       편집       편집
    대표            조회       편집       없음
    이사            조회       편집       없음
    총무            편집       편집       편집
    관리소장        편집       편집       없음
    시설관리주임    조회       편집       없음
    경리            편집       조회       없음
    미화원 · 경비   없음       조회       없음   → 나의 안전보건만
    건물주          조회       조회       없음   → 안전보건에 보이는 항목 없음(경영방침 · 이수 현황을 뺐기 때문)

■ V1과 달라진 점
--------------------------------------------------------
  · 메뉴는 2개 그룹 · 2개 화면만 남김 (V1 단지관리 화면의 동호 · 입주자단체 · 검침예외 탭은 숨기고 건물정보만 남김)
  · 로그인하지 않으면 어떤 화면도 열리지 않음 (V1은 사용자 · 권한 화면이 로그인 없이 열렸음)
  · 권한을 판단할 수 없으면 거부 (V1은 편집 허용)
  · 계정 [삭제] → [사용 안 함] / [다시 사용] — 계정은 지우지 않음
  · 건물정보: 건물 목록 표 — 건물을 누르면 [건물 기본정보] 팝업, 목록 오른쪽 위 [+ 새 건물 등록],
    각 행 끝 [삭제]. 로그인 계정의 접근 건물만 보임 (관리자 · 전체 건물 계정은 모두).
    새 건물을 등록한 계정은 그 건물에 자동으로 접근 권한이 생김. 조회 권한이면 등록 · 삭제 · 저장이 숨겨짐.
  · 수납 우선순위(연체료 방식 · 처리방식)는 화면에서 뺌 — 값은 기본값으로 보관
  · 메뉴 경로 · 사용자 · 로그아웃은 각 화면의 어두운 머리줄에 표시
  · 본인 역할 변경 금지, 관리자 역할은 시스템관리자만 줄 수 있음

■ 안전보건 화면 안의 권한
--------------------------------------------------------
  안전보건 화면 안의 버튼(교육 공지 보내기 · 결재 · 본인 서명 등)은 V1과 같은 직책 규칙을 따릅니다.
  모든 화면 머리줄의 [시연 계정 전환]으로 계정을 바꾸면 V2 메뉴와 권한(조회/편집)도 그 계정으로 바뀝니다.
  계정을 고르면 F5 없이 바로 새 화면으로 다시 열립니다. 다른 탭에 열어 둔 화면도 저절로 바뀝니다.

■ 오늘의 할 일 — 계정별로 모이는 일
--------------------------------------------------------
  🙋 나의 할 일 (현장 직원 · 관리소장): 서명 안 한 교육 공지 · 경영방침, 온라인 수강, 열린 출석 서명,
      위험성평가 회의 참석 서명 · 결과 확인, 오늘 있는 회의 · 집합교육
  🏢 우리 건물 (관리소장): 오늘 진행할 회의 · 집합교육, 기한 지난 · 7일 안 감소대책, 마감 지난 미서명자
  🏛 본사 (대표 · 이사 · 총무 · 관리자): 마감 지난 미서명 교육 공지, 결재 대기(이사 → 대표), 예정 · 지난 회의,
      기한 지난 위험요인, 이번 반기 공지 미발송(대표)
  ⚙️ 관리 (편집 권한): 처음 비밀번호 미변경 계정, 건물정보 빠진 항목
  빨강 = 지금 할 일 · 주황 = 챙길 일 · 파랑 = 오늘 · 예정. 다른 화면에서 처리하면 저절로 사라집니다.
